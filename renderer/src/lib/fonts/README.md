# Bundled social-image font

`NotoSansCJKjp-Regular.otf` is the unmodified Noto Sans CJK JP Regular font
from [Noto CJK Sans 2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004).
It includes Japanese, Latin, Chinese and Korean glyphs. The renderer uses it
only when generating social-image PNGs; it is not a browser web font.

Source: `Sans/OTF/Japanese/NotoSansCJKjp-Regular.otf` in that release.
SHA-256: `68a3fc98800b2a27b371f2fb79991daf3633bd89309d4ffaa6946fd587f375b5`.
