# Embedded renderer toolchain

This directory is owned by the CFGB executable. Content repositories do not copy it.

The lockfile pins the Astro 6 baseline and the other build tools. Astro 7 is published and is intentionally not used. Layouts, the Worker, and Pagefind integration are not in this directory yet.

`toolchain-requirements.json` at the repository root is the release pin, including the SHA-256 of `pnpm-lock.yaml`.
