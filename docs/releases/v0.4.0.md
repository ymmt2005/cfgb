CFGB — Git-based Blog on Cloudflare.

## What's new

- Rendered Mermaid diagrams have an **Expand diagram** button that opens a
  viewer filling the window. Large diagrams retain their natural size so
  labels stay readable; scroll to follow the diagram.
- Zoom in and out, fit the whole diagram to the window, or return to actual
  size. Enter native full screen where the browser permits it. Close the
  viewer or press Escape to return to the article.
- The viewer supports keyboard navigation, mobile touch controls, light and
  dark themes, and localized controls in Japanese, English, Simplified Chinese
  and Korean. Without JavaScript, the original Mermaid source remains visible.

## Build a site

CFGB implements `cfgb build` with the embedded renderer and Pagefind search.
Content repositories need only Markdown, assets, and blog settings. Use
`--base-url` and `--static` for GitHub Pages and other static hosts. Use
`--force` (or `-f`) to replace an existing output entry without confirmation
in automated builds.

Building requires Node.js and npm or pnpm compatible with the attached
`toolchain-requirements.json`. CLI setup is available through
[cfgb-action](https://github.com/ymmt2005/cfgb-action).

Authoring, migration, and Cloudflare upload commands are not implemented yet.
