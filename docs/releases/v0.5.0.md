CFGB — Git-based Blog on Cloudflare.

## What's new

- Mermaid fences now render locally with [Pele](https://github.com/obsidianmd/pele).
  Diagrams use Pele's layout and appearance, with the page's fonts and palette.
  System/light/dark theme changes update colors without replacing the SVG.
  Expand, zoom, fit, actual size and full-screen controls remain available;
  invalid diagrams and JavaScript-disabled pages retain their source.
- `cfgb deploy --from DIR` uploads an existing build artifact to Cloudflare
  without rebuilding or changing the supplied files. `--dry-run` checks the
  upload with the build's pinned Wrangler without publishing.
- CI caches renderer dependencies, and Pagefind corpus acceptance runs search
  through a native browser, including language WASM, filters and prefixed hosting.

## Optional Cloudflare deployment

On the configured production branch (default `main`):

```sh
cfgb build --force --out dist
cfgb deploy --from dist --dry-run
cfgb deploy --from dist
```

Configure `CFGB_CF_WORKER_NAME`, `CLOUDFLARE_ACCOUNT_ID` and, for a real upload,
`CLOUDFLARE_API_TOKEN`. Set `site.baseUrl` to the intended custom-domain URL and
provision its zone in Cloudflare. Deploy checks the current branch and artifact
publication snapshot, including summaries and future timestamps.

Build and deploy must share the same temporary filesystem and a compatible Node
runtime. A dry run retains the build toolchain; a real upload consumes it on
success or failure. Recreating a missing toolchain for transferred artifacts is
not implemented.

Production workers.dev and Preview/Version URLs stay disabled. Private preview
upload and Cloudflare Access verification remain future work. Cloudflare is
optional: `cfgb build --static --base-url URL` still produces a site for other
static hosts.

## Toolchain and installation

Use the attached `toolchain-requirements.json` for compatible Node.js and npm or
pnpm versions. Install the verified CLI release through
[cfgb-action](https://github.com/ymmt2005/cfgb-action) or follow the
[installation guidance](https://github.com/ymmt2005/cfgb#build-a-site).

Authoring and migration commands are not implemented yet.
