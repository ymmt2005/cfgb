CFGB — Git-based Blog on Cloudflare.

## What's new

- Article social-sharing PNGs and OpenGraph/Twitter metadata. An article's
  `ogImage` selects a local image; otherwise CFGB generates a title card.
- Optional `site.image` in `cfgb.yaml` brands generated cards and creates
  favicon and Apple touch PNGs.
- Confirmation before replacing an existing output file, directory, or symlink.
  Use `--force` (or `-f`) to skip confirmation in automated builds. The selected
  output entry and its contents are removed after confirmation or force.
- Complete example-corpus acceptance for sitemap, RSS, and article metadata
  in normal and static-host builds, with corruption regressions.

## Build a site

CFGB implements `cfgb build` with the embedded renderer and Pagefind search.
Content repositories need only Markdown, assets, and blog settings. Use
`--base-url` and `--static` for GitHub Pages and other static hosts.

Building requires Node.js and npm or pnpm compatible with the attached
`toolchain-requirements.json`. CLI setup is available through
[cfgb-action](https://github.com/ymmt2005/cfgb-action).

Authoring, migration, and Cloudflare upload commands are not implemented yet.
